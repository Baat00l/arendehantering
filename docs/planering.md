# Planering – Ärendehanteringssystem

## Syfte
Syftet med projektet är att skapa ett enkelt webbaserat ärendehanteringssystem där användare kan registrera, uppdatera och följa supportärenden. Projektet är en skoluppgift och fokuserar på att visa att jag kan bygga en full CRUD‑applikation med både frontend och backend.

## Kravspecifikation
- Responsivt gränssnitt (HTML, CSS, JavaScript)
- Backend med Node.js och Express
- Databas med SQLite
- CRUD‑funktionalitet:
  - Skapa ärende
  - Visa alla ärenden
  - Uppdatera ärende
  - Ta bort ärende
- Git‑repo med flera relevanta commits
- Dokumentation:
  - Planering
  - Teknisk dokumentation
  - Testning
- README med instruktioner

## User stories
1. Som användare vill jag kunna skapa ett supportärende så att jag kan rapportera ett problem.
2. Som användare vill jag kunna se alla ärenden så att jag får en överblick.
3. Som användare vill jag kunna uppdatera status på ett ärende så att jag kan följa arbetet.
4. Som användare vill jag kunna redigera ett ärende om jag skrivit fel.
5. Som användare vill jag kunna ta bort ett ärende som inte längre behövs.
