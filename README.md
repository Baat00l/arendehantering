# Ärendehanteringssystem

Detta är ett skolprojekt där jag bygger ett enkelt ärendehanteringssystem med full CRUD‑funktionalitet. Användaren kan skapa, visa, uppdatera och ta bort supportärenden.

## Tekniker
- Node.js + Express
- SQLite
- HTML, CSS, JavaScript

## Installation

### Backend
cd backend
npm install
node server.js

Backend körs på:  
http://localhost:3000/

### Frontend
Öppna filen:
frontend/index.html

## Funktioner
- Skapa ärende  
- Visa alla ärenden  
- Uppdatera ärende  
- Ta bort ärende
